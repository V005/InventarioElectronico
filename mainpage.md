# Sistema de Inventario Electrónico

Aplicación de escritorio desarrollada en C++ con Qt5 y SQLite3 para gestionar componentes electrónicos de laboratorio.

## Funcionalidades principales

- Registro de componentes electrónicos.
- Edición y eliminación de registros.
- Búsqueda dinámica.
- Alertas visuales de stock bajo.
- Estadísticas generales del inventario.
- Persistencia de datos en SQLite.

## Clases principales

- Componente
- DatabaseManager
- MainWindow
